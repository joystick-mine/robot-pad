듀얼쇼크 아무 버튼이나 한 번 누르면 인식돼요.
허브의 조종 프로그램이 예전 버전이에요. 새 기능이 동작하지 않을 수 있어요.

허브 준비 · 허브마다 처음 한 번만 하면 돼요

레고 허브로 이 조종기를 쓰려면 두 가지가 필요해요. ① 허브의 운영체제를 Pybricks로 바꾸기, ② 허브에 조종 프로그램 넣기.

1Pybricks 펌웨어 설치 USB 선

이미 했다면 건너뛰세요. 위의 '허브 연결'을 눌렀을 때 목록에 허브가 보이면 이미 Pybricks예요. 펌웨어를 새 버전으로 바꿀 때도 여기서 하면 돼요.

펌웨어가 뭐예요?

허브 안에서 도는 운영체제예요. 처음 산 SPIKE 허브에는 레고 펌웨어가 들어 있어서 SPIKE 앱으로만 연결돼요. Pybricks 펌웨어로 바꾸면 허브가 파이썬을 실행하고, 이 조종기와 블루투스로 대화할 수 있게 돼요. 언제든 레고 펌웨어로 되돌릴 수 있어요.

  1. 허브 전원을 끄고 USB 선을 빼요. 배터리는 충전된 상태가 좋아요.
  2. 허브의 블루투스 버튼(블루투스 모양이 그려진 작은 버튼)을 누른 채로 USB 선을 꽂아요.
  3. 블루투스 불빛이 분홍 → 초록 → 파랑으로 깜빡이면 버튼에서 손을 떼요. (업데이트 모드)
  4. 아래 USB로 펌웨어 설치를 누르고, 목록에서 LEGO Technic Large Hub in DFU Mode를 골라 연결을 눌러요.
  5. 진행 막대가 끝나면 허브가 저절로 다시 켜져요. 선을 빼고 2단계로 가요.
윈도우: 목록에 허브가 안 보이거나 '접근 거부'가 떠요

윈도우는 처음 한 번 USB 드라이버를 골라 줘야 해요. 허브를 업데이트 모드로 켜 둔 채로 따라 하세요. (컴퓨터마다 한 번만)

  1. 시작 단추를 오른쪽 클릭 → 장치 관리자.
  2. 기타 장치에서 LEGO Technic Large Hub in DFU Mode를 찾아요. 느낌표가 있으면 오른쪽 클릭 → 속성. (느낌표 없이 다른 곳에 있으면 이미 설치된 거예요)
  3. 드라이버 업데이트 → 내 컴퓨터에서 드라이버 찾아보기.
  4. 컴퓨터의 사용 가능한 드라이버 목록에서 직접 선택.
  5. 범용 직렬 버스 장치(Universal Serial Bus devices) → 다음.
  6. 제조업체와 모델 둘 다 WinUsb 장치(WinUsb Device) → 다음.
  7. '권장하지 않음' 경고가 나오면 예. 이 허브에 맞는 드라이버예요.
  8. 닫기를 누르고, 여기로 돌아와 다시 USB로 펌웨어 설치.

아예 목록에 없으면 허브가 업데이트 모드가 아닌 거예요. 위 1~3번을 다시 해 보세요.

잘 안 될 때
  • 중간에 선이 빠졌어요 → 허브는 망가지지 않아요. 다시 버튼을 누른 채 선을 꽂아 업데이트 모드로 켜고 처음부터 하면 돼요.
  • 목록이 비어 있어요 → 불빛이 여러 색으로 깜빡이는지 보세요. 그냥 켜진 상태면 업데이트 모드가 아니에요. 다른 USB 선(충전 전용 선 말고 데이터 선)도 써 보세요.
  • Pybricks Code 탭이 열려 있어요 → 그 탭이 USB를 잡고 있을 수 있어요. 닫고 다시 해요.
  • 태블릿 → OTG로 꽂으면 되는 기기도 있지만, 컴퓨터 크롬이 가장 확실해요. 아이패드는 USB 설치가 안 돼요.
  • 처음 설치하는 허브(레고 펌웨어가 든 허브)는 Pybricks 공식 저장소에서 부트로더 조각(32KB)을 받아요. 이 앱을 인터넷에서 한 번 열어 두면 그다음엔 인터넷 없이도 돼요.
레고 펌웨어로 되돌리기 · 공식 사이트에서 설치하기

레고 SPIKE 앱으로 되돌리려면 Pybricks 공식 사이트 메뉴의 Restore official LEGO firmware를 쓰세요. 공식 사이트에서 펌웨어를 설치해도 돼요.

Pybricks 공식 사이트 열기 ↗

설치되는 펌웨어: Pybricks v4.1.1 (SPIKE Prime 원래 허브 · 새 허브 둘 다). Pybricks 팀이 만든 MIT 라이선스 오픈소스이고, 설치 순서는 Pybricks 공식 설치 도구와 같아요. 허브를 살려 내는 레고 기본 부트로더(맨 앞 32KB)는 절대 건드리지 않아요.

2조종 프로그램 넣기

허브에 조종 프로그램(hub_program)을 블루투스로 넣어요. Pybricks Code 사이트에 갈 필요 없어요.

  1. 허브 전원을 켜요. (Pybricks Code 탭은 닫아 두세요)
  2. 아래 버튼을 누르고 허브를 골라요. 이미 연결돼 있으면 바로 시작해요.
  3. 진행 막대가 끝나면 끝. 바로 조종할 수 있어요.

허브에 있던 다른 프로그램은 지워지고 조종 프로그램으로 바뀌어요. 넣은 프로그램은 허브 버튼으로 전원을 끄면 저장돼서 다음에 켜도 남아 있어요.
